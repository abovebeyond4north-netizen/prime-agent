# Learned procedure versus supplied scaffold

Executed October 13, 2026 at code commit 7dbfccf292752ddb8edd136283e8d66ea0466505.

## Result: continuation ties; learning has an upfront cost

All nine paired rule trials tied. For each rule in each seed, both arms consumed 30 containers: 14 for fresh certification with retention checks and 16 for extra shifted validation. Both used a predeclared 40-container ceiling. Their normalized source hashes matched. Every candidate passed all ten gates, and 9,216 additional 256-bit cases passed across both arms, with exact integer boundary inequalities checked independently of the bitwise task oracle.

Shared study preparation used 42 containers: 12 to certify the supplied lower-bound donor and 30 additional containers to discover and certify the square-root procedure model. The supplied adapter can construct candidates without a learned procedure model. Both continuation arms inherit the same certified state, however, including square-root certification. A separate matched cold-start experiment was not executed, so subtracting all 30 containers from a hypothetical baseline total would overstate the evidence. The measured setup cost establishes no cold-start advantage.

Both methods abstained on the predeclared ambiguous rule (4,2,3,4) before any candidate container was started. Its public examples cannot uniquely identify the predicate within the existing grammar.

## Measurement boundary

The procedure configuration is frozen after square-root training; the receiving rules never update it. Each receiving predicate is inferred from its public labels. Both arms use the same active certified donor and square-root source during fresh regression checks. The supplied baseline receives no secret rule coefficients; it uses the same public-driven predicate expansion and adapts the certified BOUND AST. Extra shifted seeds never enter selection. Arm order reverses on even seeds.

The rule list and budgets were fixed in the code commit before Docker comparisons. Public identifiability was checked during fixture design: one ambiguous quartic fixture was rejected and retained as the explicit abstention test. These are withheld from procedure training, not externally withheld domains.

The previous 38.6% saving remains valid against repeated rediscovery. It must not be presented as an advantage over a supplied correct scaffold. This experiment closes that comparator gap with a negative result.

## Verification and scope

Local full discovery: 156 tests, 148 passed, eight Docker-dependent skips. Project checks passed without warnings. No production behavior, protected evaluator, promotion gates or default flags changed. Source and full reports are in scaffold_baseline_results.json; Actions artifacts retain raw results for 30 days.

All runs share an operator and environment class. The same bounded developer-defined grammar and evaluator remain in use. Equal container counts establish no CPU or wall-time equivalence claim. No automatic promotion or open-world capability claim.

Next useful work should seek new representational/transfer capability or reduce cold-start discovery cost. More repetitions of the identical canonical scaffold comparison are unlikely to change its container-count conclusion.
